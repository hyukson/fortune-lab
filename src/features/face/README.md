# 관상 (담당: 장혁수)

## 사용 라이브러리

| 라이브러리 | 용도 |
|---|---|
| `@mediapipe/tasks-vision` Face Landmarker | 얼굴 특징점 478개, 표정 점수, 고개 각도 |
| `@mediapipe/tasks-vision` Image Segmenter (hair) | 머리카락 영역 → 이마 위 머리카락 경계(상정 길이) |
| `@mediapipe/tasks-vision` Face Detector | 작은 얼굴까지 다시 세서 콜라주·포스터·여러 명 사진 거르기 |
| `p5` | 스캔 연출과 결과 화면의 얼굴 측정 그림 (`ui/FaceCanvas.tsx`) |

모델 파일은 `public/models/face/`에 있습니다 (`face_landmarker.task` 3.7MB, `hair_segmenter.tflite` 0.8MB, `blaze_face_short_range.tflite` 0.2MB).
모든 분석은 브라우저 안에서 실행되고 사진은 서버로 보내지 않습니다.

## 화면 흐름

```
안내(IntroStep) — 성별 선택(선택 사항)
  ├─ 카메라 촬영(CameraStep): 조건이 맞으면 자동 촬영, 6초 뒤 "직접 찍기" 버튼
  └─ 사진 올리기 / 끌어다 놓기
        ↓
스캔 연출(ScanStep) ── 통과 ──→ 결과(ResultStep)
        └──────────── 탈락 ──→ 다시 찍기 안내(RetryStep)
```

## 폴더 구조

```
face/
├─ FacePage.tsx      화면 단계 전환
├─ config.ts         ⭐ 모든 숫자 기준 (검사 기준, 분류 범위, 점수 가중치)
├─ types.ts
├─ core/             계산 (화면과 무관)
│  ├─ landmarker.ts  MediaPipe 모델 불러오기 (CPU 고정)
│  ├─ image.ts       파일 검사, 크기 통일, 밝기·선명도
│  ├─ geometry.ts    특징점 번호, 고개 각도, 기울기 보정
│  ├─ surface.ts     피부색 측정 (마스크 감지)
│  ├─ faceCount.ts   얼굴 수 다시 세기 (콜라주·여러 명)
│  ├─ hairline.ts    이마 위 머리카락 경계 찾기
│  ├─ validate.ts    사진 품질 검사
│  ├─ measure.ts     비율 측정
│  ├─ reading.ts     측정값 → 풀이·점수
│  └─ analyze.ts     위 과정을 한 번에 실행
├─ content/          문구 (풀이 readings.ts, 안내 messages.ts)
└─ ui/               화면 컴포넌트
```

## 산출 방식

1. **검출**: 사진의 긴 변을 1024px로 맞춘 뒤 특징점 478개를 찾습니다.
2. **검사**: 아래 조건에 걸리면 분석하지 않고 다시 찍기를 안내합니다.
3. **측정**: 두 눈을 수평으로 맞춘 뒤 비율을 잽니다 (사진 크기와 무관).
   - 얼굴 길이÷너비, 눈꼬리 각도, 눈 사이÷눈 길이, 콧볼÷얼굴 너비, 입÷얼굴 너비, 턱÷얼굴 너비
   - 삼정: 머리카락 경계 ~ 미간 ~ 코 밑 ~ 턱 끝의 세로 비율. 앞머리로 경계가 가려지면 이마 위쪽 특징점까지로 재고 같은 방식의 평균과 비교
4. **풀이**: 측정값을 한국인 표본의 기준 범위(아래 25% / 위 25%)와 비교해 낮음/보통/높음으로 나누고 문구를 연결합니다. 성별을 고르면 같은 성별 기준을 씁니다.
5. **지표 점수**: `SCORE_RULES`의 가중치로 재물·애정·대인·직업·건강 점수를 계산하고, 가장 높은 지표가 대표 유형이 됩니다.

무작위 요소가 없어서 같은 사진이면 항상 같은 결과가 나옵니다.

## 걸러내는 사진

| 사진 | 코드 |
|---|---|
| 동물·풍경·물건·애니·일러스트 (얼굴 없음) | `NO_FACE` |
| 여러 명·콜라주·포스터 (작은 얼굴까지 다시 셈) | `MULTIPLE_FACES` |
| 얼굴이 작거나 잘림 | `FACE_TOO_SMALL`, `FACE_CUT_OFF` |
| 옆모습·숙임·기울임 | `HEAD_TURNED`, `HEAD_PITCHED`, `HEAD_TILTED` |
| 활짝 웃음·입 벌림·눈 감음 | `SMILING`, `MOUTH_OPEN`, `EYES_CLOSED` |
| 어둡거나 너무 밝거나 흐림 | `TOO_DARK`, `TOO_BRIGHT`, `BLURRY` |
| 선글라스 (간이 방식) | `EYES_COVERED` |
| 마스크 | `MASK` |
| 깨진 파일·지원하지 않는 형식·저해상도 | `FILE_BROKEN`, `FILE_TYPE`, `IMAGE_TOO_SMALL` |

## 기준값 보정 기록 (face-v1.2)

| 항목 | 표본 | 결과 |
|---|---|---|
| 분류 범위 `RANGES` | 정면·무표정 한국인 265명 (여 176, 남 89): 위키미디어 공용 CC 사진 32명 + 팀이 수집한 연예인 웹 이미지 233명 | 부위별 낮음/보통/높음 ≈ 25% / 50% / 25% |
| 삼정 평균 `SAMJEONG` | 위 265명 (머리카락 경계 찾음 202명, 앞머리 등 63명) | 머리카락 경계 기준 0.30 / 0.37 / 0.34 |
| 대표 유형 `SCORE_RULES.base` | 위 265명 | 다섯 유형이 각 16~26% |
| 마스크 `maxMaskScore` | 마스크 안 쓴 얼굴 1,092장 / 실제 마스크 착용 25장 | 착용 24장 감지, 마스크 검사만으로 막히는 정상 사진 0장 |
| 얼굴 수 `FACE_COUNT_RULES` | 함정 사진(콜라주·포스터·2인 등) + 정상 사진 377장 | 여러 얼굴 함정 10장 중 9장 차단, 혼자 찍은 사진 오탐 0장 |

웹 이미지는 서양인·AI 합성 얼굴·그림·콜라주를 눈으로 확인해 제외했습니다. 사진은 통계 산출에만 쓰고 레포에는 넣지 않았습니다.

**한계**
- 표본이 연예인 위주(보정·화장이 많은 사진)라 일반인 셀카와 분포가 다를 수 있습니다.
- AI 합성 얼굴, 보정이 심한 사진, 사실적인 회화 초상화는 실제 얼굴처럼 통과합니다. 애니·일러스트는 대부분 얼굴 검출 단계에서 걸러집니다.
- 실시간 카메라는 가짜 카메라 영상으로만 시험했습니다.

## 다시 보정하는 방법

1. `npm run dev`로 실행하고 관상 페이지를 엽니다.
2. 개발 모드에서는 `window.__faceDev.analyzeFile(file)`로 사진을 화면 없이 바로 분석할 수 있습니다 (측정값·검사값 반환).
3. 통과한 사진들의 측정값에서 아래 25% / 위 25% 지점을 `RANGES`의 `low` / `high`로 넣습니다.
4. 대표 유형이 한쪽으로 쏠리면 `SCORE_RULES`의 `base`를 1~2점씩 조정합니다.
5. 기준을 바꿨으면 `RULE_VERSION`을 올립니다.

결과 화면 아래 "개발용 측정값"과 "점 번호 보기"는 개발 모드에서만 보입니다.
